# Red Bead Experiment App Icon Guide

## Quick Icon Creation

Since your Red Bead Experiment app is about statistical process control, here are some icon ideas:

### **Icon Concept 1: Chart with Beads**
- Background: Clean white or light blue
- Main element: Simple line chart/control chart
- Accent: Small red and white circles (representing beads)

### **Icon Concept 2: Statistical Symbol**
- Background: Professional blue/gray gradient
- Main element: Sigma (σ) symbol or bell curve
- Accent: Small dots representing data points

### **Icon Concept 3: Simple Beads**
- Background: Clean gradient
- Main element: Circular container with red and white beads
- Style: Minimalist, flat design

## How to Add Your Icon:

### **In Xcode:**
1. **Assets.xcassets** → **AppIcon**
2. **Drag your icon files** into the appropriate slots
3. **Required sizes for iPhone:**
   - 40x40pt (80x80px) - Spotlight
   - 60x60pt (120x120px, 180x180px) - App icon
   - 1024x1024px - App Store

### **Quick Online Tools:**
- **App Icon Generator**: Search for "iOS app icon generator"
- **Canva**: Has iOS app icon templates
- **SF Symbols**: Apple's built-in symbols (chart.xyaxis.line fits perfectly!)

### **Using SF Symbols as Base:**
Your app already uses `chart.xyaxis.line` - you could create an icon based on this:
1. Screenshot the SF Symbol in large size
2. Add it to a colored background
3. Export as PNG in required sizes

## Temporary Fix:

If you need a quick placeholder icon, you can:
1. Create a simple colored square with the text "RBE" (Red Bead Experiment)
2. Use any image editing app
3. Export in 1024x1024 size
4. Use online tool to generate all required sizes
